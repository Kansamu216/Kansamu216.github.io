欢迎来到我的博客 🎉 这里会随手记录一些想法、折腾笔记和日常。

## 这个博客怎么来的

用 [Hexo](https://hexo.io/) 搭的静态博客，主题是 [Fluid](https://hexo.fluid-dev.com/)。写 Markdown，一条命令生成静态网页，部署到哪里都很省心。

## 写文章就三步

1. 新建一篇文章：

   ```bash
   hexo new "文章标题"
   ```

2. 打开 `source/_posts/` 下生成的 `.md` 文件，用 Markdown 写正文。

3. 本地预览（实时刷新）：

   ```bash
   hexo server
   ```
